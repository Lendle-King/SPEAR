# SPEAR research workspace

Research repository for **SPEAR: Learning What Evidence to Seek for Parameter-Level Self-Improvement in LLM Agents**.

The initial manuscript is maintained as a research draft (LaTeX source, bibliography, and prespecified experimental protocol) in a separate paper branch before review and merge.

**Scope:** parameter-intervention value of information (PI-VOI), evidence-conditioned functional parameter interventions, and recursively learned diagnostic/update policies.

**Research integrity:** proposed mechanisms and planned evaluations are distinguished from experimentally validated findings. No numerical results are claimed before execution.

**Naming note:** another 2025/2026 agentic-RL method uses the SPEAR acronym (Qin et al., arXiv:2509.22601); this manuscript title is provisional.
