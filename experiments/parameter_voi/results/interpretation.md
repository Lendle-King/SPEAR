# Synthetic seed-42 smoke run — scientific interpretation (2026-10-30)

**Important:** this is a two-parameter toy model with synthetic evidence and validation costs. **It is not a run of Qwen, LoRA, AndroidWorld, an actual teacher API, or a real document retrieval system**. The values below were generated by the checked-in CPU implementation and do not validate the scientific novelty of SPEAR.

## Protocol

`python -m experiments.parameter_voi.run --seed 42 --train 360 --test 240 --meta-train 240 --meta-test 240 --out <directory>`

- 180 phase0 direction-learning worlds, 180 disjoint phase0 source-value-learning worlds, 240 held-out phase0 worlds in 120 latent-opposite pairs.
- 240 additional phase1 meta-replay worlds, 240 held-out phase1 worlds in 120 pairs.
- Each phase0 policy gets at most one query and one proposed intervention validation per world; no-query exhaustive search evaluates both signs (two validations).
- `source_cost = 0.04`, `candidate_validation_cost = 0.18`, `old-parameter-protection_cost = 0.02` in **arbitrary synthetic utility units**; these are not real-world resource costs.
- Positive test gain means better strict held-out toy tasks with no evidence reinjected. All reported policy net values **exclude the cost of collecting and fitting the shared meta-training archive**; this is not an end-to-end efficiency claim.

## Held-out phase0 (240 synthetic worlds)

| Arm | Strict toy success | Mean net toy utility | Query calls per world |
|---|---:|---:|---:|
| No update | 50.0% | 0.000 | 0 |
| Fixed teacher + learned direction | 79.6% | 0.101 | 1 |
| Preferred source by task kind | 84.2% | 0.146 | 1 |
| Strong readiness-rule + learned direction | 90.4% | 0.179 | 1 |
| **PI-VOI + learned direction** | **90.6%** | **0.181** | **1** |
| PI-VOI + **static semantic** direction | **90.6%** | **0.181** | **1** |
| Exhaustive no-query two-candidate search | **100.0%** | 0.135 | 0 |

Matched-pair bootstrap, `PI-VOI + learned` minus readiness-rule net toy utility: **+0.0021**, 95% interval **[-0.0125, +0.0167]**. The interval includes zero and the gap is tiny. **The learned acquisition policy does not establish an advantage over the strong simple rule.**

Likewise, `PI-VOI + learned direction` minus `PI-VOI + static semantic direction` is **exactly 0 in this controlled run**. **The evidence-to-parameter generator has not demonstrated an independent benefit over an appropriate static semantic rule.** This is a critical negative result for the proposed *joint* method claim.

The exhaustive no-query baseline obtains a full 100% synthetic success rate because it evaluates both candidate signs with an exceptionally informative, cheap deterministic checker. It has slightly lower synthetic *net utility* only under this **chosen** validator/source cost ratio. Changing this ratio may reverse that ranking. Real adaptation costs must be measured.

## Other gate smoke checks

- **Constructed reversal:** 120/120 matched pairs have opposite best numeric parameter changes, by explicit dataset construction. This is **not a discovered property of real agent failures**.
- **Retention stress:** 66/66 synthetic shared-parameter unsafe updates were rejected by the old-skill gate. This validates rollback plumbing only.
- **Sequential meta-update:** phase1 adaptive-minus-frozen net toy utility = **+0.0399**, paired bootstrap 95% **[+0.0128, +0.0667]**, in a deliberately shifted evidence-reliability model. Both arms can access the same growing example archive; only adaptive refits. This shows the toy can detect meta-adaptation, not authentic recursive LLM improvement.

## Conclusion / real experiment blockers

**CPU mechanism and audit checks: complete. Empirical paper gates G1–G4 for LLM agents: NOT ESTABLISHED.**

The next meaningful test must evaluate real Qwen3.5-4B updates in paired resettable tool-agent episodes, using the same checkpoint, matched candidate-evaluation budget, *all* observable failure features for the strong rule, and held-out full episodes without re-injected text. Randomized source assignment and real monetary/compute cost ledgers are essential. A claimed gain requires separation from the strong same-input rule and static semantic intervention generator, not simply beating fixed teacher or no-update.
